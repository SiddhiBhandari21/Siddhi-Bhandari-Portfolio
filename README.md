# Siddhi Bhandari — Portfolio

Plain HTML / CSS / JS. No build step.

```
index.html      page content (edit text here)
style.css       all styling (colors at the top under :root)
script.js       menu, tabs, project filters, dark mode, scroll effects
assets/profile.jpg               your photo
assets/Siddhi_Bhandari_Resume.pdf  file served by "Download Resume"
```

## Before publishing
1. GitHub links point to github.com/SiddhiBhandari21.
2. To update your resume later, overwrite `assets/Siddhi_Bhandari_Resume.pdf` with the same file name.

## Host free on GitHub Pages
1. Create a public repo named `SiddhiBhandari21.github.io`.
2. Upload all files (keep the `assets` folder).
3. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/root`.
4. Your site goes live at `https://SiddhiBhandari21.github.io` in a minute or two.

To preview locally, just double-click `index.html`.
